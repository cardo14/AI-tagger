This is the repo used to store the Computer Vision Automated Tagger developed for the UCLA tennis team to collect data on match videos. The data processing files help us convert the output data into data that is useful for us to compute match statistics and build reports. I developed the model adapting code from the following repo: [https://github.com/yastrebksv/TennisProject](https://github.com/yastrebksv/TennisProject, adjusting homography and other details to fit UCLA's court camera system.

Please see output.mp4 for a working example of how the model operates on tennis video.
